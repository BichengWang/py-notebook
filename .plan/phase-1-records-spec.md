# Phase 1: records as a specification (2026-11-02 → 2026-12-13)

Goal: a third party can validate and verify every record type without our
Python packages; a forged record that was re-hashed fails when a signature is
required; expgate's statistics agree with reference implementations; all of it
ships as 0.2.0 on PyPI.

| ID | Task | Owner | Depends on | Acceptance |

| P-011 | **JSON Schemas and conformance vectors per record type.** JSON Schema 2020-12 files shipped as package data (`<package>/schema/<record>.v<N>.json`) for every current schema: expgate `decision.json`, Jev answer, evaluation and provenance, decision-control exported record and `evaluation.json`. Vectors under `ai-workflows/<project>/conformance/{valid,tampered,invalid}/`; each valid vector carries its exact canonical bytes and digest so other languages can test their canonicalizer. | P-013 | **Cross-check expgate statistics against reference implementations** (dev-only, pinned; runtime stays standard library).
